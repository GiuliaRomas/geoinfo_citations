# Análise Bibliométrica dos Trabalhos do GEOINFO

Este repositório contém os códigos, dados processados e notebooks desenvolvidos para a análise bibliométrica dos trabalhos publicados no **Simpósio Brasileiro de Geoinformática (GEOINFO)** e das publicações que os citam.

O projeto contempla etapas de **coleta, padronização, enriquecimento, integração e análise dos dados bibliográficos**, permitindo caracterizar a produção científica do evento e investigar sua influência por meio das citações recebidas.

## Objetivos

O projeto tem como objetivos:

- organizar e padronizar os metadados dos trabalhos publicados no GEOINFO;
- identificar as publicações que citam os trabalhos do evento;
- complementar os metadados bibliográficos por meio de diferentes fontes;
- comparar a cobertura das bases utilizadas na identificação das citações;
- realizar análises bibliométricas da produção científica e das citações do GEOINFO.

## Fontes de dados

Foram utilizadas diferentes fontes para a coleta e o enriquecimento dos dados:

- **GEOINFO** — trabalhos publicados nas edições do evento;
- **Google Scholar** — identificação e coleta de trabalhos citantes;
- **OpenAlex** — identificação de trabalhos, citações e metadados bibliográficos;
